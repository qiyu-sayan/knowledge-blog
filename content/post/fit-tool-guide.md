**Fit Tool v1.2** 网页版：在浏览器里绘制运动轨迹并生成 FIT 跑步文件，**无需安装**，打开即用。

**→ 打开工具：[开始使用 Fit Tool](/fit-tool/)**

> 本工具仅供学习与技术交流，请遵守所在学校 / 平台的相关规定，风险自负。

## 快速上手

1. 点击上方链接进入工具  
2. 在右侧**地图上点击**绘制轨迹点（自动连成路线）  
3. 设置心率、体重、圈数、导出份数、开始时间与配速  
4. 点 **预览曲线** 确认配速 / 心率  
5. 点 **生成 FIT 文件**，浏览器会下载 `run.fit`  
6. 将文件导入目标 App / 设备  

## 界面说明

### 地图

- **点击**：添加轨迹点，自动连线  
- **清除轨迹**：重新画  
- 地图使用**天地图**底图，显示范围限国内  

### 「搜索地点」——推荐定位方式

不依赖 GPS：输入 **学校 / 体育馆 / 公园名**，点搜索，再点结果即可跳过去。

这是最稳的方式，尤其电脑定位不准、或 Windows 位置缓存错误时。

### 「尝试获取当前位置」

用于快速定位。**电脑上经常不准**（IP 猜测或系统缓存，例如错误地落在南昌·安义县）。

现在点它会先**反查地名并让你确认**：

- 显示「定位到：某某市…」→ 选 **「是，就用这里」** 或 **「不对，我自己点图」**  
- 拒绝时地图**不会乱跳**

| 场景 | 建议 |
|------|------|
| 电脑定位不准 / 一直错 | 用「搜索地点」 |
| 手机浏览器 | 可用「尝试获取当前位置」，精度通常较好 |
| 任何情况 | 直接在地图上点起点，效果一样 |

### 参数

| 参数 | 作用 |
|------|------|
| 静息 / 最大心率 | 生成心率曲线的上下限 |
| 体重（kg） | 估算卡路里，输入会记住 |
| 圈数 | 轨迹重复次数；多圈时加轻微抖动更接近真人 |
| 导出份数 | 一次生成多个 FIT，可分别设开始时间和配速 |
| 配速 | min/km，决定总用时与速度曲线 |

### 生成与导入

1. 建议先 **预览曲线** 看配速是否合理  
2. **生成 FIT 文件**（本地生成，不经过服务器）  
3. 把 `.fit` 导入 Keep / Garmin Connect / 其他支持 FIT 的工具  

## 隐私说明

- 地图密钥使用站点统一配置，无需你填写  
- 体重等偏好仅存在**你自己浏览器**的 localStorage  
- FIT 在浏览器本地生成，本站不收集运动数据
