欢迎使用 **Fit Tool v1.2** 网页版。这是一个在浏览器里绘制运动轨迹、生成 FIT 跑步文件的工具（原为本地 Node 小工具，现已迁到本站，**无需安装**）。

**→ 打开工具：[开始使用 Fit Tool](/fit-tool/)**

> 本工具仅供学习与技术交流，请遵守所在学校 / 平台的相关规定，风险自负。

## 快速上手

1. 点击上方链接进入工具  
2. 首次进入会弹出 **「登录并设置天地图密钥」**  
3. 粘贴你自己的天地图密钥 → **校验并进入**  
4. 在右侧地图上**点击**绘制轨迹点（自动连成路线）  
5. 设置心率、圈数、导出份数、开始时间与配速  
6. **预览曲线** 确认无误后 → **生成 FIT 文件**  
7. 将 `.fit` 文件导入目标 App / 设备  

## 一、如何获取天地图密钥（tk）

本工具的地图底图来自**天地图**，需要你自己的开发者密钥：

1. 打开 [天地图控制台](https://console.tianditu.gov.cn/)，注册并登录  
2. 进入 **应用管理 → 创建新应用**  
3. 服务类型选择 **浏览器端**（Web 端）  
4. 创建后复制得到的 **32 位密钥**（形如 `9fe5d147fae873e0…`）  
5. 回到工具页，粘贴到弹窗输入框，点 **「校验并进入」**  

**说明**

- 密钥只保存在**你自己浏览器的本地存储**中，不会上传到本站服务器  
- 勾选「记住我」后，下次进入**免登录**直接使用  
- 点侧栏 **「更换密钥 / 退出登录」** 可随时清除  

## 二、关于「尝试获取当前位置」

这个按钮用于快速把地图定位到你附近，再画轨迹。

### 为什么有时会定位到「南昌 · 安义县」之类的奇怪位置？

那通常**不是 GPS**，而是浏览器在无法获取卫星定位时，用 **IP 地址粗略猜测**的位置（运营商出口常落在某地级市/县城），误差可达几十上百公里。

**你现在可以这样处理：**

| 场景 | 建议 |
|------|------|
| 电脑（无 GPS） | 不必强求定位，直接在地图上点选起点 |
| 手机浏览器 | 允许「定位权限」+ 打开系统「定位服务」，精度通常可用 |
| 定位偏差很大 | 页面会提示「低精度位置」，请忽略并手动点图 |

### 按钮没反应 / 失败提示？

- 浏览器地址栏 → 权限图标 → 允许 **定位**  
- 手机：系统设置 → 隐私 / 定位服务 → 打开，并允许该浏览器  
- 仍失败就 **手动点地图**，完全等价  

## 三、参数说明

| 参数 | 作用 |
|------|------|
| 静息 / 最大心率 | 生成心率曲线的上下限 |
| 体重（kg） | 估算卡路里，会记住你的输入 |
| 圈数 | 轨迹重复次数；>1 圈时会加轻微抖动更像真人 |
| 导出份数 | 一次生成多个 FIT，可分别设开始时间与配速 |
| 配速 | min/km，决定用时与速度曲线 |

## 四、隐私与安全

- 天地图密钥、昵称、体重等仅存在 **本地浏览器**（localStorage）  
- FIT 文件在**你的浏览器里直接生成**，不经过本站服务器  
- 本站不收集账号、密码或运动数据
