**Fit Tool v1.2** 网页版：在浏览器里绘制运动轨迹并生成 FIT 跑步文件，**无需安装**，打开即用。

**→ 打开工具：[开始使用 Fit Tool](/fit-tool/)**

> 本工具仅供学习与技术交流，请遵守所在学校 / 平台的相关规定，风险自负。

## 快速上手

1. 点击上方链接进入工具  
2. 在右侧**地图上点击**绘制轨迹点（自动连成路线）  
3. 设置心率、体重、圈数、导出份数、开始时间与配速  
4. 点 **预览曲线** 确认配速 / 心率  
5. 点 **生成 FIT 文件**，浏览器会下载 `run.fit`  
6. 将文件导入目标 App / 设备  

## 界面说明

### 地图

- **点击**：添加轨迹点，自动连线  
- **清除轨迹**：重新画  
- 地图使用**天地图**底图，显示范围限国内  

### 「尝试获取当前位置」

用于把地图快速定位到你附近再画轨迹。

**为什么有时会定位到很偏的地方（例如南昌·安义县）？**  
电脑没有 GPS 时，浏览器会用 **IP 地址粗略猜测**，误差可能几十上百公里。此时页面会提示「低精度位置」。

| 场景 | 建议 |
|------|------|
| 电脑（无 GPS） | 不必点定位，直接在地图上点起点 |
| 手机浏览器 | 允许定位权限 + 打开系统定位，一般较准 |
| 提示定位失败 | 看页面引导：检查权限，或手动点图 |

手动点图的效果与定位后画轨迹**完全一样**。

### 参数

| 参数 | 作用 |
|------|------|
| 静息 / 最大心率 | 生成心率曲线的上下限 |
| 体重（kg） | 估算卡路里，输入会记住 |
| 圈数 | 轨迹重复次数；多圈时加轻微抖动更接近真人 |
| 导出份数 | 一次生成多个 FIT，可分别设开始时间和配速 |
| 配速 | min/km，决定总用时与速度曲线 |

### 生成与导入

1. 建议先 **预览曲线** 看配速是否合理  
2. **生成 FIT 文件**（本地生成，不经过服务器）  
3. 把 `.fit` 导入 Keep / Garmin Connect / 其他支持 FIT 的工具  

## 隐私说明

- 地图密钥使用站点统一配置，无需你填写  
- 体重等偏好仅存在**你自己浏览器**的 localStorage  
- FIT 在浏览器本地生成，本站不收集运动数据
