**随机地址生成器**：一键生成虚构的姓名、地址、电话、邮箱等，适合**表单测试、UI 演示、开发占位**。

**→ 打开工具：[立即生成随机地址](/address-gen/)**

> 数据均为**本地浏览器随机生成**，不联网、不上传。仅供测试演示，请勿用于欺诈或违法用途。

## 功能

| 功能 | 说明 |
|------|------|
| **多地区** | 美国 / 英国 / 中国 字段格式 |
| **批量生成** | 一次 1～200 条（虚拟城市级组合） |
| **复制** | 单条或全部复制到剪贴板 |
| **字段** | 姓名、街道、城市、邮编、电话、邮箱、公司等 |

## 怎么用

1. 打开上方工具链接  
2. 选 **地区**（美 / 英 / 中）  
3. 填 **条数** → 点 **生成**  
4. 点 **复制本条** 或 **复制全部** 粘贴到测试表单  

## 适用场景

- 注册 / 收货表单联调  
- 设计稿假数据  
- 接口 mock 示例  
- UI 空状态填充
