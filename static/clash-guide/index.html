一、电脑版 · Clash Verge

1. 打开「订阅」，粘贴订阅链接并新建

左侧菜单选 订阅 → 顶部输入框粘贴订阅链接 → 点 新建。然后点选要使用的配置卡片。

2. 填写新建配置

名称：备注名；订阅链接：粘贴 URL；更新间隔建议 1440 分钟。其余默认，点保存。

3. 首页：打开系统代理、选模式

打开 系统代理；代理模式选 规则（日常）/ 全局（排错）/ 直连（不走代理）。右侧可切换节点。

二、手机版 · Clash Meta for Android

1. 打开 App，进入「配置」

2. 点右上角「+」新建

3. 选择「URL」导入

4. 填写名称与订阅，自动更新 1440

5. 回到主页启动

6. 「代理」页右上角菜单 → 切换模式

7. 选择节点

模式怎么选

模式含义何时用
规则国外走代理，国内直连日常默认
全局全部走代理排错时临时
直连不走代理关闭加速
